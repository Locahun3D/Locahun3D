# Original Equipment Assets

These six GLBs are generated from `src/js/274_equipment_geometry.js`, originally authored for this Locahun3D project. Matching WebP thumbnails are CPU renders of those GLBs. No third-party mesh, manufacturer CAD, photograph, logo, or texture is redistributed. Distribution follows the repository's terms.

Manufacturer names identify representative dimensional references only. These are simplified location-planning proxies, not manufacturer-certified technical or safety models. See `docs/equipment-models-2026-09-11.md` for exact variants, cited dimensions, modeling assumptions, asset sizes, and reproduction commands.
