# Locahun3D viewer — agent rules

- **Edit only `src/`** (modules `src/js/NNN_*.js`, `src/css`, `src/html`). Never edit the built `Locahun3D_OfflineViewer.html` / `*.online.html` / `viewer-dist/` by hand — they are regenerated by `node build.mjs`.
- Build: `node build.mjs`. Deploy: `bash deploy-viewer.sh` (builds, syncs `viewer-dist/`, runs `wrangler deploy` to Worker `locahun3d` = https://viewer.locahun3d.com). Deploy only when the owner says so. Online copy sync: `bash sync-online-viewer.sh` (see `README.md`).
- `_headers` (copied into `viewer-dist/`) gives HTML `Content-Type: text/html; charset=utf-8` — required, otherwise Discord/OGP link previews show mojibake. Keep it.
- Vendored Spark lives in `vendor/` (see `vendor/README.md`); `worker.js` serves `/vendor/*` with CORS and `/api/demo-asset/*` from R2 (`ALLOWED_KEYS` allowlist).
- Test harnesses: URL params `?demo=1`, `orbit=1`, `capture=1`, `autoinit=1`, `showcase=1` (feature tour). Device-specific behaviour is detected from real DOM state, not media queries.
- Verify in a real browser on desktop and phone sizes before claiming a fix. Dropbox sync has previously rolled files back — git is the source of truth; commit early.
